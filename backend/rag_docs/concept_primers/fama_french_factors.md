# Fama–French multifactor decomposition (primer)

SMB (small minus big market cap tilt premium proxy), HML (high minus low book-to-market — value tilt), profitability (RMW) and conservative investment / asset growth contrasts (CMA) augment market factor Mkt-RF.

Typical empirical workflow: regress portfolio excess returns on factor returns to attribute performance rather than asserting causality from one sample.
